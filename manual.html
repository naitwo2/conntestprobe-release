ConnTest Probe 利用・操作マニュアル

Windows 11 高精度ネットワーク疎通・経路監視プローブツールの機能と操作リファレンス

1. アプリケーション概要

ConnTest Probe は、Windows 11専用の高精度ICMP Ping通信断監視およびTraceroute経路比較テストツールです（Windows 11のみ対応）。

主な特徴
  • 500ms単位の通信断精密計測: 1回の一時的なパケット欠落から長期断まで、ミリ秒精度（00:00:00.500など）でダウンタイムを即座に特定。
  • Traceroute 3段履歴比較: 「期待値」「前回実行結果」「選択した実行時刻」を縦並び・ホップ横展開で比較し、経路変更箇所や応答変化をハイライト表示。
  • 障害連動の自動Traceroute: Pingの連続失敗時間を検知し、同一障害中に1回だけ自動でTracerouteを実行。
  • タスクバー常駐対応: ウィンドウを閉じてもバックグラウンドでテストを継続。通知領域からいつでも復帰可能。
  • SQLiteストリーミングZIP出力: 長時間の大量明細ログを軽量SQLiteに蓄積し、必要時にZIP・CSVとして一括エクスポート。

2. 画面レイアウト・操作性

多数のシナリオを監視する業務環境を考慮し、固定ヘッダー（Sticky Header）と温かみのあるアンバー調の配色を採用しています。

画面構成
  • トップバー (App Header):
    • タブ切替: テストシナリオ設定 と 実行結果 を切り替え。
    • シナリオ操作: 取込 保存 ボタン。
    • 実行制御: Ping・Tracerouteの 実行 / 停止。
    • 結果エクスポート: 「自動保存」チェック、CSV ZIP エクスポートボタン。
  • 固定ヘッダー付きテーブル: 画面をスクロールしても、表の見出し列（選択、ID、IP/FQDN等）が固定表示されるため、横スクロール・縦スクロール時も対象を迷わず把握できます。
  • 右下ステータス: β版利用期限情報（例: β版 2027年1月31日まで利用可能）および言語切替（日本語 / 英語）を表示。

3. テストシナリオCSV仕様

テスト対象および実行パラメータはCSVで一括インポート・エクスポートできます。CSVはヘッダー付きの10列フォーマットです。 

ip,source_ip,ping_payload_bytes,ping_timeout_ms,ping_interval_ms,max_hops,trace_timeout_ms,expected_route,memo,auto_trace
127.0.0.1,,56,500,500,8,500,127.0.0.1,ローカル疎通確認 #Local #確認,3000
192.168.1.1,192.168.1.100,56,500,1000,15,500,192.168.1.1,拠点ルータ #GW,
example.com,,,500,1000,20,500,10.0.0.1>* >-,Webサービス #Cloud,5000
列名 必須 設定範囲 / 既定値 説明
ip ○ IPv4アドレス または FQDN テスト対象。FQDNは自動でIPv4へ名前解決されます。
source_ip - IPv4アドレス（空欄可） パケットの送信元IP。空欄時はOSのルーティングテーブルに基づき自動選択。
ping_payload_bytes - 1〜65500（既定: 56） Pingパケットのペイロードサイズ (bytes)。
ping_timeout_ms - 100〜5000（既定: 500） Ping応答待ちタイムアウト (ms)。
ping_interval_ms - 500〜300000（既定: 500） Ping送信間隔 (ms)。
max_hops - 1〜255（既定: 30） Tracerouteの最大TTLホップ数。
trace_timeout_ms - 100〜5000（既定: 500） 各ホップでの応答待ちタイムアウト (ms)。
expected_route - ホップを > で区切る 期待する経路。ワイルドカード * や - を利用可能。
memo - 任意のテキスト #Core や #Branch などのハッシュタグを含めると画面上で絞り込み可能。
auto_trace - 1000〜300000（空欄可） Ping連続失敗時にTracerouteを自動実行するまでの時間(ms)。1000ms単位で指定。
CSV互換性について

・auto_trace 列のない従来の9列CSVもそのままインポート可能です（自動実行は無効として扱われます）。
・旧バージョンの group 列が含まれるCSVを読み込んだ場合、自動的にメモ末尾のハッシュタグ（例: #Group名）へ変換されます。

4. IPリスト (ホストカタログ)

ネットワーク内のIPアドレスと機器名・役割（説明）をマッピングした hosts.csv を管理できます。

形式例 機能・効果 
ip,description
192.168.1.1,コアルーター
10.0.0.1,社内DNSサーバー
 Tracerouteのホップ結果や実行結果の宛先表示において、該当するIPアドレスにマウスカーソルを重ねると機器名称（ツールチップ）が表示されます。経路調査の視認性が大幅に向上します。

「IPリスト管理」モーダルから直接行の追加・編集・CSV取込・出力が可能です。

5. Ping監視・通信断計測

「Ping / 実行」を押すと、各シナリオの ping_interval_ms に従ってリアルタイムにテストが開始されます。

個別実行と一括実行

  • 未選択時: 一覧にあるすべてのシナリオを同時に実行します。
  • チェックボックス選択時: チェックを付けた特定のシナリオのみを対象に実行・停止できます。

高精度な通信断（Downtime）判定

  • 通信断時間は 500ms単位 で判定され、00:00:01.500 のようにミリ秒まで正確に表示・記録されます。
  • TTL超過の検出: ルーティングループ等によるTTL expiredパケットを通常タイムアウトと明確に区別し、「TTL超過」として検知・集計します。
Pingメトリクス集計表示
Ping実行中: N件 Ping(最新): 送信 X件 / 異常 Y件 通信断(最新): リアルタイム発生件数 通信断(履歴): 過去に断があった件数 平均RTT / ロス率

6. Traceroute・経路履歴比較

Tracerouteを実行すると、宛先までのホップごとの応答アドレスおよびRTTを計測し、期待ルートとの比較を行います。

期待ルート (ExpectedRoute) のマッチング記法

記号 / 表記 例 マッチング判定仕様
IP / FQDN 192.168.1.1 そのホップの応答IPが完全一致する場合のみOK。
* (アスタリスク) 10.0.0.1 > * > 10.0.0.3 中継ルーターが無応答（タイムアウト）になることが必須のホップ。応答があった場合は不一致。
- (ハイフン) 10.0.0.1 > - > 10.0.0.3 ワイルドカード（無視）。タイムアウトでも任意のIP応答でも一致と判定。

3段履歴比較（Traceroute詳細モーダル）

結果行をクリックして開く詳細画面では、直近最大1,000回分のTraceroute履歴を閲覧・比較できます。

比較テーブル構造
  • 1段目 (期待値): 設定された ExpectedRoute のホップ一覧。
  • 2段目 (前回): 選択した実行結果の直前1回分の計測ホップ。
  • 3段目 (選択時刻): 選択中の実行結果。変化したホップは淡い黄色（#fff8e9）で強調され、「変更」「追加」「削除」「応答変化」が表示されます。

7. 自動Traceroute機能

シナリオの auto_trace にミリ秒（例: 3000 = 3秒）を設定しておくと、Ping監視中に障害が発生した瞬間の経路情報を自動追跡できます。

動作ルール
  • Pingの連続失敗時間が auto_trace で指定した時間に達すると、自動的にTracerouteを1回トリガーします。
  • 多重実行防止: 同じ通信断が継続している間は1度だけ実行され、無駄な連続Tracerouteによる負荷を防ぎます。
  • Pingが正常に復帰するか、テストを停止した時点でトリガー状態がリセットされ、次回障害時に再び自動実行可能になります。

8. 結果エクスポートとDB管理

CSV / ZIP 出力

  • CSV出力: 各シナリオの最新Pingステータス、RTT、ロス率、最新/累積通信断時間、Traceroute最新結果を1行ずつサマリ出力します。
  • ZIP出力: サマリCSVに加え、バックグラウンドのSQLiteからストリーミング生成されたPing/Tracerouteの全生明細CSV（時系列ログ）をパッケージして出力します。

データクリーンアップ

  • 生明細の保持期間は24時間です（10分ごとに古いデータを自動削除）。
  • 画面側の生明細・通信断履歴は各対象の直近1,000件までメモリ上に保持されます。
  • アプリ正常終了時に一時SQLiteファイルは自動削除され、個人情報やセッション情報を安全に破棄します。

9. タスクバー常駐・終了制御

テスト実施中に誤ってウィンドウを閉じてしまうトラブルを防ぐため、Windows環境では終了制御ダイアログが作動します。

  • タスクバーに常駐する: ウィンドウのみを非表示にし、通知領域（システムトレイ）にアイコンを残して監視テストを継続します。アイコンのダブルクリックまたは右クリックメニュー「ウィンドウを表示」で即座に再表示できます。
  • 完全に終了する: 実行中のテストを安全に停止し、セッションデータをクリアしてアプリケーションを終了します。

10. 制限事項・仕様詳細

項目 内容・制限値
対応OS Windows 11 のみ対応
対応プロトコル IPv4 のみ対応（IPv6 は今後の対応予定）
シナリオ登録上限 無料版 / β版: 最大 50 行（上限到達時は行追加ボタンが無効化されます）
履歴保持 Traceroute / 通信断履歴: 各シナリオ直近 1,000 件（アプリ終了時に消去）
ライセンス期間 β版は 2027年1月31日まで 利用可能（起動時および画面右下に表示）
権限要件 ICMPパケット送受信のため、必要に応じて管理者権限または適切なネットワーク権限が必要です。

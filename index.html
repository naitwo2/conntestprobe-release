ネットワーク疎通確認と
エビデンス保全を、これひとつで。

ConnTest Probe（コンテストプローブ）は、切り替え工事や現地トラブルシュートにおける通信試験を効率化するネットワークエンジニア向けテストツールです。 並列Ping、自動Traceroute、そして取り忘れを防ぐ詳細エビデンスの自動保存に対応。

現場の「困った」を解消する主な機能

シンプルで無駄のない画面設計で、日々の運用テストから夜間切り替え作業まで確実にサポートします。

⚡

並列 Ping 実行

複数拠点や複数機器のIPリストに対し、同時に並列Pingを実行。全対象の疎通ステータスやRTTの揺らぎを一目で素早く把握できます。

💻 Probe
Host A (192.168.1.1) OK (1ms)
Host B (10.0.0.254) OK (3ms)
Host C (172.16.2.1) NG / Timeout
1つの画面から全ホストへ同時パケット送出・即時可視化
🧭

Traceroute（期待値比較）

事前に定義したホップごとの「期待経路」と実際の経路を自動比較。通常時と異なる経路を通っている場合にハイライト表示します。

期待値
GW → Core-A → Dest
VS
実際値
GW → Core-B（迂回） → Dest
設計経路（正本）との差分をホップ単位で自動検知
🔄

Pingダウン時の自動 Traceroute

Ping通信断をトリガーに、自動でTracerouteを実行します。ネットワーク切り替わり後の経路変化を記録します。

1. Ping監視 通信断検知（Loss 100%）
⚡ 自動トリガー
2. Traceroute起動 新経路のホップ・停止位置を追跡
切り替わり瞬間・途絶箇所の証跡を逃さずキャッチ
💾

テスト終了時の自動保存

試験停止と連動してログ・エビデンスファイルを即座にローカルへ自動保存。「結果を保存し忘れた」という現場のヒューマンエラーを防止します。

■ 停止ボタン押下
自動連動
📁 results/conntest-202701.csv
📦 results/evidence-bundle.zip
停止操作のみでタイムスタンプ付きフォルダに確実保存
📋

詳細なエビデンス出力

開始終了時刻、各送信パケットの統計、タイムスタンプ付きのPing・Traceroute実行履歴など、報告書作成や顧客提出にそのまま活用できる高品質なエビデンス（CSV / ZIP）を生成します。

⏱ タイムスタンプ ミリ秒単位の送受信時刻
📊 パケット統計 送信数・応答数・ロス率・RTT
🗺 ホップ別追跡ログ IP・ホスト名・各試行RTT・合否
📦 一括アーカイブ CSV生データ＋Zip形式で出力
作業報告書や検収エビデンスにそのまま添付できる客観データ
